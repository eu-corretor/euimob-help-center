No **CRM**, cada cliente interessado vira uma oportunidade no pipeline e anda
pelas etapas até o negócio fechar. Os leads dos portais, do site e do
WhatsApp chegam aqui sozinhos. Os que chegam por telefone, plantão ou
indicação, você cadastra.

## O que dá para fazer

| Para quê | Guia |
| --- | --- |
| Registrar um cliente e acompanhá-lo até o ganho | [Cadastrar um cliente no pipeline](/crm/cadastrar-um-cliente-no-pipeline/) |
| Faturar a comissão do negócio ganho | [Faturar a comissão](/financeiro/faturar-a-comissao/) |
| Receber os leads dos portais imobiliários | [Enviar imóveis para os portais e receber os leads](/integracoes/portais-imobiliarios/) |

Para acompanhar, filtrar oportunidades e ajustar etapas e funis, com vídeos,
veja o [treinamento Do cliente à comissão](/treinamento/vendas/).
