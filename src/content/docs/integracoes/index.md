**Caminho:** Integrações → Integrações
**Atalho:** `/painel/integracoes`
**Quem faz:** gestor

---

As integrações ligam o Eu Imob a outros sistemas. Você cadastra os imóveis uma
vez só, e o sistema cuida do resto: leva os anúncios aos portais, traz os
leads para o CRM e mantém tudo atualizado de hora em hora.

## O que dá para fazer

| Para quê | Onde aprender |
| --- | --- |
| Anunciar nos portais (VivaReal / ZAP, OLX, Chaves na Mão, ImovelWeb, SP Imóveis) e receber os leads no CRM | [Enviar imóveis para os portais e receber os leads](/integracoes/portais-imobiliarios/) |
| Trazer para o seu sistema os imóveis de DWV, Bloco (antigo Studio 360) ou Órulo | [Aula: trazer imóveis de construtoras](/treinamento/integracoes/trazer-imoveis-de-construtoras/) |
| Manter um catálogo de imóveis no Facebook com o link do XML | [Aula: criar um catálogo de imóveis no Facebook](/treinamento/integracoes/catalogo-de-imoveis-no-facebook/) |

## Acompanhar as integrações

A lista de **Integrações** mostra o **Status** de cada uma. Quando algo falha,
abra a integração e veja a aba **Logs**: a mensagem diz o que aconteceu. O
histórico de todas fica em **Integrações → Logs** (`/painel/logs-integracao`).
